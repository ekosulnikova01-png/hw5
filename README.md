## 1. Docker-окружение

**Объяснение:**
В Docker контейнеры временны. Если контейнер удалить, все файлы внутри него исчезнут. Volume (том) - это специальное хранилище на жестком диске хоста. Когда мы монтируем том в папку `/var/lib/postgresql/data` (где PostgreSQL хранит свои данные), все изменения записываются на жесткий диск. 

Даже если контейнер сломается почему-то или будет удален, данные останутся в томе, и новый контейнер сможет их прочитать. Это физически обеспечивает свойство Durability (Надежность) из ACID: после команды `COMMIT` данные не потеряются при сбое.

## 3. Исследование WAL и Durability

**Скриншот изменения LSN:**
![Скриншот WAL](image-5.2.png)

**Объяснение:**
LSN - это указатель на текущую позицию в журнале WAL. При выполнении `COMMIT` PostgreSQL не записывает изменения напрямую в файлы таблиц (они остаются в оперативной памяти в `shared_buffers`). Вместо этого он сначала записывает информацию об изменениях в специальный журнал `pg_wal/` и синхронно сбрасывает его на диск с помощью `fsync`. Только после этого транзакция считается зафиксированной. Если сервер внезапно выключится, при запуске он прочитает WAL и восстановит все данные. Это и есть гарантия Durability.
